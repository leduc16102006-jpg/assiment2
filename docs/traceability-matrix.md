## 3. Ghi chú phạm vi thực thi hiện tại (Minh bạch nghiệm thu)

- **FR-04 (`GET /auth/me` & thu hồi JWT):** Bản MVP hiện triển khai xác thực JWT stateless (`POST /auth/register`, `POST /auth/login`); khi người dùng đăng xuất, Frontend xóa token khỏi `localStorage` và dọn trạng thái giỏ hàng hiển thị. Cơ chế blacklist/revocation phía server chưa triển khai trong phiên bản này.
- **FR-08 (`PATCH /orders/:id/status`):** Endpoint hiện bảo vệ bằng `JwtAuthGuard` và kiểm tra State Machine hợp lệ; chưa tách phân quyền vai trò Barista/Admin (vì quản trị Barista thuộc mục `FR-13 Won't` của SRS) để phục vụ kịch bản kiểm thử mô phỏng `PAYMENT_FAILED` (Task 8) trực tiếp trên giao diện.
- **NFR-03 (PWA):** Bản MVP hoàn thiện giao diện Mobile-First, Web App Manifest (`standalone`) và bộ icon vuông PNG (`192×192`, `512×512`). Service Worker offline caching chưa triển khai trong phạm vi Assignment 2 (chi tiết xem `ADR-002`).
